# 🗄️ 백엔드 필수 개념

백엔드 개발에 꼭 필요한 개념을 **8개 단원**으로 나눠 공부하는 학습 사이트입니다.
단원마다 **개념 학습 → 단어 암기 → 단원 퀴즈 → 오답노트** 순서로 진행하고, 모든 단원을 마치면 **전체 정리 · 종합 퀴즈 · 전체 오답노트**로 마무리합니다.

👉 **사이트 바로가기: https://worksenddl2-source.github.io/backend-study/**

## 📚 단원 구성

| 단원 | 주제 | 주요 내용 |
|---|---|---|
| 1 | 웹의 동작 원리 | 클라이언트·서버, IP·포트, DNS, URL 구조, TCP/UDP, URL 입력 시 일어나는 일 |
| 2 | HTTP | 무상태성, 메서드, 상태 코드, 헤더, 쿠키·세션, HTTPS/TLS |
| 3 | API 설계 | REST, RESTful URI 규칙, JSON·직렬화, 멱등성, 페이지네이션, 버저닝 |
| 4 | 데이터베이스 | RDB, SQL·JOIN, 정규화, 인덱스, 트랜잭션·ACID, NoSQL, ORM·N+1 |
| 5 | 인증과 보안 | 인증·인가, 세션 vs JWT, OAuth 2.0, 해싱·솔트, SQL Injection·XSS·CSRF, CORS |
| 6 | 서버 아키텍처와 성능 | 웹 서버·WAS, 모놀리식·MSA, 스케일 업/아웃, 로드 밸런서, 캐시, 메시지 큐, CDN |
| 7 | 운영체제와 동시성 | 프로세스·스레드, 동기·비동기, 동시성·병렬성, 경쟁 상태·락, 데드락, 커넥션 풀 |
| 8 | 개발·배포·운영 | Git·PR, 테스트, CI/CD·배포 전략, Docker, 클라우드, 환경 변수·모니터링 |

단원마다 개념 카드 6개, 핵심 용어 13~17개(총 121개), 직접 작성한 퀴즈 6~7문제가 있습니다.

## ✨ 기능

### 단원별 학습
- **📖 개념 학습**: 개념 카드를 한 장씩 넘기며 읽습니다. 읽은 카드는 자동으로 체크됩니다.
- **🔤 단어 암기**
  - 카드 암기: 카드를 뒤집어 뜻을 확인하고 `알아요` / `모르겠어요`로 분류합니다.
  - `모르는 단어만` 모드로 못 외운 단어만 반복할 수 있습니다.
  - 목록 보기: 전체 단어표, 뜻 가리기(마우스를 올리면 보임), 외움 상태 토글.
- **📝 단원 퀴즈**: 개념 문제와 단어 문제(자동 생성) 4개를 섞어 10문제 안팎을 냅니다. 객관식과 OX 문제가 있고, 답을 고르면 바로 정답과 해설이 나옵니다.
- **❌ 오답노트**: 틀린 문제와 내 답, 정답, 해설, 틀린 횟수가 저장됩니다. `오답 다시 풀기`에서 맞히면 자동으로 지워집니다.

### 최종 마무리
- **📚 전체 정리**: 단원별 핵심 요약과 핵심 단어를 한 페이지에 모았습니다.
- **🔎 전체 단어장**: 모든 용어를 검색할 수 있고, 못 외운 단어만 보기와 뜻 가리기를 지원합니다.
- **🏆 종합 퀴즈**: 단원별 개념 2문제와 단어 4문제로 20문제를 냅니다. 풀 때마다 새로 섞입니다.
- **❌ 전체 오답노트**: 모든 단원과 종합 퀴즈의 오답을 단원별로 묶어 보여주고, 한 번에 다시 풀 수 있습니다.

### 그 밖의 기능
- 학습 현황 대시보드: 읽은 개념, 외운 단어, 완료한 단원, 오답 수, 이어서 학습하기
- 진도는 브라우저(localStorage)에 자동 저장됩니다. 사이드바 하단에서 초기화할 수 있습니다.
- 키보드 단축키
  - 단어 카드: `Space` 뒤집기 / `←` 모르겠어요 / `→` 알아요
  - 퀴즈: `1`~`4` 보기 선택 / `O`·`X` / `Enter` 다음 문제
- 다크 모드(시스템 설정을 따름)와 모바일 화면 지원

## 🚀 실행 방법

빌드나 설치 과정이 없는 정적 사이트입니다.

```bash
git clone https://github.com/worksenddl2-source/backend-study.git
cd backend-study
# index.html을 브라우저로 열면 바로 실행됩니다.
```

## 📁 파일 구조

```
├── index.html   # 페이지 뼈대
├── style.css    # 스타일 (라이트/다크, 반응형)
├── data.js      # 학습 데이터: 단원, 개념, 단어, 퀴즈, 요약
└── app.js       # 라우팅, 진도 저장, 단어 암기, 퀴즈 엔진, 오답노트
```

## ✏️ 내용 추가·수정

모든 학습 내용은 `data.js`의 `UNITS` 배열에 있습니다. 단원 객체를 하나 추가하면 사이드바, 퀴즈, 전체 정리에 자동으로 반영됩니다.

```js
{
  id: 9,
  title: "새 단원",
  desc: "한 줄 설명",
  concepts: [{ title: "개념 제목", body: "<p>HTML 본문</p>" }],
  terms: [["용어", "뜻"]],
  quiz: [
    { type: "mc", q: "질문", options: ["A", "B", "C", "D"], answer: 0, explain: "해설" },
    { type: "ox", q: "질문", answer: true, explain: "해설" }
  ],
  summary: ["핵심 요약 1", "핵심 요약 2"]
}
```
